# Meeting Effectiveness Scorer

## 概要
参加人数・時間・平均時給を入力してミーティングコストを算出し、アジェンダ達成度チェックリスト（5項目）のスコアを掛けて効率点を算出する生産性ツール。

## 機能
- 参加人数・時間・時給からミーティング総コスト計算
- 5項目のアジェンダ達成度チェックリスト
- 実効価値・潜在的無駄コストの算出
- 効率スコア（0〜100%）とレーティング（Excellent/Good/Fair/Poor）
- 改善提案の表示

## 使い方
参加人数・会議時間・平均時給を入力し、5つのチェックリスト項目を評価してください。リアルタイムで効率スコアとコスト分析が更新されます。
